6月16日课后教师半结构访谈大纲

1. 一天时间线活动

今天从“手表 / 闹钟”转到“一天时间线、白天 / 夜晚、上午 / 中午 / 下午”。从老师角度看，学生进入这个主题是否容易？请举一个具体学生或小组的例子。

(如何判断进入)学生是通过看图、指认、移动卡片、口头回答、生活经验，还是通过作品制作进入这个概念的？

2. 当天观察片段 1：__________

刚才我们观察到：__________。老师会怎样解释这个行为？它更像是理解时间概念、材料兴趣、感官调节、模仿、等待，还是任务困难？

  • 老师或助教做了什么支持？
  • 学生后面有没有回到任务或改变行为？

4. 时间概念回应

今天哪些学生对“白天 / 夜晚、上午 / 中午 / 下午”有可观察回应？这些回应是语言、指认、看向、移动卡片、作品选择，还是身体 / 情绪状态变化？

  • 哪些回应可以说明学生在参与时间概念？举例子
  • 哪些只能说明学生在参与材料或作品制作？哪个学生，什么材料和步骤
  • 哪些地方还不能确定，需要视频、field note 或作品再核对？

5. 太阳 / 月亮制作中的材料行为

今天哪些材料明显帮助学生参与？哪些材料造成困难、回避或离开？

  • 哪些学生对某类材料有明显偏好或回避？
  • 如何理解这些互动行为？这些行为应该理解为参与、调节、探索，还是偏离任务？

6. 教师和助教支持

今天哪些支持方式最有效？例如提示、示范、等待、手把手协助、减少材料、替换材料、情绪支持。

  • 哪些学生需要降低制作步骤？
  • 哪些学生需要降低时间概念要求？
  • 哪些学生其实可以给更多选择或创造空间？

RQ 对齐提醒

  • RQ1： 记录学生如何通过材料选择、触摸、重复、回避、替换或制作动作表现 tactile-material engagement。
  • RQ2： 把观察到的动作、表达和作品痕迹转化为可追踪描述时，需要区分低推论观察和老师解释。
  • RQ3： 记录老师如何解释学生行为，并如何通过提示、示范、等待、协助、换材料或情绪支持进行 scaffolding。
