Touch-to-Meaning Observation Workshop Protocol

Purpose: paper methods and RQ-data-results mapping.

Study Frame

This 30-minute classroom workshop observes how neurodivergent learners engage with tactile and material elements while making a clock. The study does not diagnose students, test a finished intervention, use LLM-generated data, or claim causal learning effects. The goal is to make the route from observation to interpretation traceable.

Participants: 8 students in 4 pairs, 1 main teacher, 3 assistant teachers, and 3 on-site researchers.

Task: make a beautiful clock using card-paper circular clock bases, colored pens, clay, felt/non-woven fabric, clock hands, and attachment materials.

Task levels:

  • A: open-ended clock making with material selection, number points, and hand placement.
  • B: scaffolded clock making with prepared options and guided hand placement.
  • C: simplified clock making with prepared parts and supported participation.

Recording setup: 4 group 360 cameras total, with one 360 camera for each student pair/group. Each 360 camera can support both front-view and top-down/tabletop review during analysis, depending on camera placement and exported view. The current June 2 setup does not use separate fixed top-down and front-view cameras.

Teacher interview: 30 minutes with three teachers after the workshop.

Research Questions

These research questions move from observing tactile response patterns, to translating multimodal expression, to tracing educator interpretation, and then building a framework.

RQ1. Tactile response patterns
What tactile response patterns emerge when neurodivergent learners engage with tactile materials in a structured learning activity?

RQ2. Traceable semantic descriptions
How can learners’ multimodal expressions around tactile episodes be translated into traceable semantic descriptions of tactile experience?

RQ3. Educator interpretation
What educator knowledge is needed to interpret and respond to learners’ tactile expressions?

RQ4. Salience of semantic descriptions
How salient and stable are the semantic descriptions of tactile experience across multiple sessions?

Note on RQ4: the June 2 workshop can identify candidate semantic descriptions and test the mapping structure, but salience and stability require evidence across multiple sessions.

Step 2. Participant Profile Design

Use profiles to support interpretation, not to diagnose or rank students.

Profile fields:

  • Participant code and pair code.
  • Task level: A, B, or C.
  • Teacher-rated pre/post knowledge score.
  • Communication mode: speech, gesture, pointing, AAC, object choice, silence, other.
  • Fine-motor support needs: cutting, drawing, placing, shaping, attaching, hand use.
  • Sensory/material notes: preferred, avoided, uncertain, or high-support materials.
  • Attention/regulation support: preview, repetition, adult prompt, break, peer model, object focus.
  • Teacher-known classroom routines or behavior labels.
  • Consent/recording status.

Pair profile fields:

  • Pair code.
  • Student pairing rationale if known.
  • Peer interaction pattern to watch for: shared work, parallel work, imitation, helping, conflict, turn-taking.
  • Assigned group 360 camera ID.

Structured Behavior Descriptors

Material/action descriptors:

  • Material choice: selected, accepted, rejected, switched, returned to.
  • Touch type: tap, press, rub, pinch, roll, squeeze, trace, hold, avoid.
  • Construction action: cut, draw, color, shape, paste, place, remove, repair, rotate.
  • Repetition: repeated same action, repeated material choice, repeated placement.
  • Persistence: continues after difficulty, pauses, abandons, asks for help.
  • Clock/time action: places number point, aligns position, attaches hand, rotates hand, points to time.
  • Artifact state: no mark, partial mark, number point present, hand present, completed clock.

Interaction/support descriptors:

  • Orientation: toward task, teacher, peer, material, camera, away.
  • Engagement display: watching, reaching, manipulating, waiting, wandering, disengaging.
  • Regulation signal: calm, hesitation, frustration, withdrawal, repetitive action, self-soothing action.
  • Help-seeking: looks to teacher, raises hand, verbal request, gesture, hands object to adult.
  • Peer interaction: watches peer, imitates, shares material, takes turn, resists, negotiates.
  • Teacher support received: prompt, demonstration, physical/material assistance, praise, redirection, pause.
  • Expression mode: speech, gesture, facial expression, body movement, object action, silence in context.

Do not code internal states directly. Code visible behavior first, then link interpretation to teacher labels, field notes, and evidence.

Step 4. Analysis Pipeline

Software: NVivo.

  1. Import data by pair/group, 360 camera file, and segment label.
  2. Create cases for each student, each pair, and each teacher.
  3. Segment videos by S1-S6 and by pair-level events.
  4. Run first-pass descriptive coding on group 360 video for hand-material actions, artifact-making, orientation, peer interaction, and teacher support.
  5. Use field notes, photos, audio, and student work to supplement what the 360 video cannot show clearly.
  6. Select key clips for teacher behavior labeling.
  7. Code teacher interview and teacher labels.
  8. Enter teacher-rated pre/post knowledge scores as case attributes.
  9. Build evidence-linked descriptions: observed action + media evidence + teacher label + interpretation limit.
  10. Compare evidence across field notes, video, audio, photos, student work, teacher labels, and knowledge score.
  11. Build RQ-data-results matrix.
  12. Write unsupported-claim log before drafting results.

Core output:

  • RQ-data mapping matrix.
  • Participant/pair profile table.
  • Dry-run coding table.
  • NVivo codebook.
  • Teacher behavior-label memo.
  • Knowledge score summary.
  • RQ-data-results matrix.
  • Unsupported-claim log.
