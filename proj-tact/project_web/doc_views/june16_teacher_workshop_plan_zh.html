一天时间线：昼夜与上午中午下午概念活动工作坊计划（教师版）

活动主题： 一天时间线：白天 / 夜晚、上午 / 中午 / 下午 时间： 2026 年 6 月 16 日 对象： 数学美社老师、在场助教老师、7 名参与学生 时长： 约 30 分钟

一、活动目标

本次工作坊延续前两周的“生活时间 + 触觉材料制作”课堂形式。学生先通过一天时间线认识白天、夜晚、上午、中午和下午，再在 A/B/C 小组手工活动中制作太阳或月亮。活动重点不是测试学生是否能一次性说出完整定义，而是观察学生如何通过材料、作品、动作和老师支持进入时间概念。

主要目标：

  • 学生通过一天时间线认识白天和夜晚，以及上午、中午、下午的生活时间段。
  • 学生在太阳 / 月亮制作中用材料表达对时间段的理解。
  • 老师和助教老师支持学生选择材料、完成作品、展示表达，并观察学生如何回应时间概念和材料任务。

二、材料准备

材料类别 具体材料 用途 课堂关注点
时间线材料 一天时间线图、白天 / 夜晚提示卡、上午 / 中午 / 下午提示卡 帮助学生看到一天中的时间顺序 是否能看向、触摸、指认、移动或回应时间段
底板材料 圆形卡纸、深色 / 浅色底纸、作品底板 制作太阳、月亮或时间段作品 选择形状、放置位置、理解太阳 / 月亮关系
触觉材料 毛根、橡皮泥、贴纸、海绵、布料、亮片或其他安全触觉材料 做太阳光线、月亮边缘、云、星星或装饰 触摸、按压、揉捏、重复、替换、回避
标记材料 彩色笔、粗线笔 标记时间段、颜色、个人装饰 颜色选择、标记位置、是否需要协助
固定材料 胶棒、双面胶、安全固定件 固定太阳 / 月亮元素和装饰 是否能等待、继续、请求帮助或调整

建议每组桌面先放少量材料，备用材料由老师统一管理。材料不做编号；只在作品收集时给学生作品贴编号。

四、课堂活动流程

本次活动的主线是“先认识一天时间线，再用太阳 / 月亮手工作品表达时间段”。0-2 共同属于概念介绍阶段；第 3 阶段根据小组和学生情况选择制作太阳或月亮。阶段用于课堂提示和观察记录，不是严格计时关卡。

阶段 名称 课堂重点
0-2 概念介绍阶段 0 看一天时间线；1 区分白天 / 夜晚；2 把上午 / 中午 / 下午放到一天时间线上，联系生活情境。
3A 制作太阳 粘贴卡纸、绘画、卷一卷卡纸条。
3B 制作月亮 贴一贴，把圆形片贴在月亮形状上。
4 展示与表达 展示作品，表达完成、继续、更换、帮助、暂停或停止。
