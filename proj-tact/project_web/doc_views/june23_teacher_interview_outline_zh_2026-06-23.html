6月23日课后教师半结构访谈大纲

访谈问题

1. 今天活动的整体进入情况（约4分钟）

今天从“白天 / 夜晚、上午 / 中午 / 下午”进一步进入“计划我的一天”和“时间段与时钟匹配”。从老师角度看，内容的连续性。

  • 哪些学生能够把日常活动和时间段联系起来？
  • 哪些学生只是参与了材料或贴放动作，但还不能确定是否理解时间段？

2. 当天观察片段1：__________（约4分钟）

刚才我们观察到：__________。老师会怎样解释这个行为？它更像是时间段理解、时钟匹配、材料兴趣、感官调节、模仿、等待，还是任务困难？

  • 当时前面发生了什么？后面学生有没有回到任务或改变行为？
  • 老师或助教做了什么支持？

3.这个行为在前几次工作坊中是否出现过类似模式？

  • 这次因为活动变成时间表海报，学生表现有没有变化？
  • 需要看之前或之后的课堂情境、field note、作品照片或视频才能判断吗？

4. 时间表海报和作品痕迹（约3分钟）

今天的“我的一天”时间表海报是否比前几次单个作品更容易帮助学生表达？哪些作品痕迹能帮助老师解释学生的选择、理解或参与？

  • 海报上的活动顺序、时间段位置、时钟卡、触觉标记或装饰是否有可解释意义？
  • 哪些痕迹是学生自己选择或调整的？哪些主要来自老师协助？

5. 材料行为、偏好（约3分钟）

今天哪些材料明显帮助学生参与？哪些材料造成困难、回避、或把学生带离任务目标？

  • 哪些学生对某类材料有稳定偏好或回避？这种模式是否从前几次工作坊延续下来？
  • 这些行为应该理解为参与、调节、探索、兴趣表达，还是偏离任务？
  • 哪些材料需要减少、替换、预处理或由老师控制数量？

7. 教师和助教支持方式（约3分钟）

今天哪些支持方式最有效？例如提示、示范、等待、局部身体辅助、减少材料、替换材料、情绪支持、把任务拆成一个动作。

  • 哪些学生需要降低制作步骤？哪些学生需要降低时间概念或时钟匹配要求？
  • 哪些学生其实可以给更多选择、创造空间或更高阶任务？
  • 上一次提到的0-3手工能力评估表，是否能帮助后续更准确地安排任务分层？

8. 四次工作坊后的稳定模式与变化（约5分钟）

回顾6月2日、6月9日、6月16日和今天四次工作坊，老师觉得哪些学生参与模式、材料偏好、支持需求或表达方式已经比较稳定？哪些还在变化？

  • 哪些变化可能来自学生熟悉了工作坊流程？
  • 哪些变化可能来自活动设计本身，例如从时钟、手表 / 闹钟、太阳 / 月亮，到今天的时间表海报？

上一次6月16日访谈的核心发现

以下内容用于开场快速回顾，帮助本次访谈承接前一次教师解释。访谈时不需要逐条确认，除非老师有补充或修正。

  • 单纯区分“白天 / 黑夜”相对容易，但把白天、夜晚、上午、中午、下午迁移到不同生活场景时，学生会遇到明显困难。
  • 同伴观察和模仿不一定只是抄或分心，也可能说明学生正在关注他人、学习流程或尝试进入任务。
  • 教师支持需要随学生和当下材料状态调整，包括口头提示、示范、等待、局部身体辅助、材料预处理或只要求完成一个关键动作。
